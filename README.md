# Blood & Organ Donation Platform 

A web-based platform that connects blood and organ donors with recipients in need. The project aims to make the donation process faster, easier, and more accessible through a digital system.

##  Features

- Donor registration system
- Recipient request management
- Search and match donors
- Blood group-based filtering
- Organ donation support
- User-friendly interface
- Secure data management

##  Technologies Used

- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js, Express.js
- Database: MongoDB

##  Project Purpose

The goal of this project is to encourage donations and create a platform where people can quickly find suitable donors during emergencies.
